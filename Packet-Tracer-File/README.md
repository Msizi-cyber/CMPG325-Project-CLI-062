# Packet Tracer File

This folder contains the complete Cisco Packet Tracer implementation for the Dikgatlong Adventure Tourism network.

## File Contents

| File | Description |
|------|-------------|
| `Dikgatlong_Network_Project(New).pkt` | Complete working network simulation |

## How to Open

1. Install **Cisco Packet Tracer 8.x** or later
2. Open the `.pkt` file
3. All devices are pre-configured
4. Test connectivity from any PC

## Network Summary

- **7 Devices:** ISP Router, Edge Router, Core Switch, 2 Staff PCs, 1 Guest PC, 1 Server
- **4 VLANs:** Management (10), Staff (20), Servers (30), Guest (40)
- **Routing:** Router-on-a-Stick + Default Route to ISP
- **Security:** ACL for Guest isolation + SSH management
